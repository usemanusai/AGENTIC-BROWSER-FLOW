# agentic_browser_flow Flow

This project defines a declarative CrewAI Flow in `src/agentic_browser_flow/flow.yaml`.

## Install

```bash
crewai install
```

## Run

```bash
crewai run
```

Edit the declarative flow definition at `src/agentic_browser_flow/flow.yaml` to change the flow. Add reusable crews under `src/agentic_browser_flow/crews/`, custom Python tools under `src/agentic_browser_flow/tools/`, and shared knowledge files under `src/agentic_browser_flow/knowledge/`.
